# 0002：依据实际宿主能力选择接入路线

状态：已采用本地浏览器路线；原生宿主兼容性待观察。日期：2026-10-10。

本地预览服务与报告已在 Codex 内置浏览器打开。P1 使用浏览器展示、画布级上下文复制和版本轮询。
原生工具 UI、thread 元数据和标准消息适配已实现，但当前聊天未加载本项目 MCP 服务，不能确认原生能力。
证据与每项未知原因见 [本机接入观察](../compatibility/2026-10-10-local-preview.md)。

## 背景

官方公开了 MCP App 会话入口、主题、模型上下文和消息扩展，但本机 Codex 的支持情况尚未运行确认。SDK 中不支持的扩展可以缺失；文档平台名称和示例不能代替实际结果。

## 决策

- 首阶段实现最小宿主探针，记录标准能力与扩展能力。
- 每项能力独立报告 supported、unsupported 或 unknown。
- 支持时使用原生 UI 和消息接口；不足时保留浏览器预览与反馈复制。
- 对缺失能力显示可理解的状态，避免静默空动作。
- 使用服务端画布身份绑定界面，不假设能获取桌面聊天 ID。
