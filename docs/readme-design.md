# README 信息架构与素材维护

日期：2026-10-11。适用：[中文首页](../README.md) 与 [英文首页](../README.en.md)。

## 结构参考

阅读以下项目的原始 README 后，借鉴其信息顺序与展示方式；没有复制文案、截图或品牌素材。

| 项目 | 借鉴的组织方式 | 本项目的对应设计 |
|---|---|---|
| [Excalidraw](https://github.com/excalidraw/excalidraw) | 简短定位、效果展示、功能与开始使用 | 首屏说明用途，工作台截图展示整体，再提供画廊 |
| [Mermaid](https://github.com/mermaid-js/mermaid) | 按图表类型呈现示例，链接代码与文档 | 六种场景，每张实拍图对应可运行 TSX；架构使用 Mermaid |
| [LobeHub](https://github.com/lobehub/lobehub) | 语言切换、功能与图片配对、分层文档入口 | 同步中英文首页，单独展示 Design mode，维护信息链接到专门文档 |

首页顺序：定位 → 工作台 → 场景画廊 → 主要能力 → 快速体验 → 安装 → 两张原理图 → 数据与文档 → 贡献与许可证。

## 保持可验证

- 图片必须来自可运行示例，素材来源与截取范围记录在 [图片说明](assets/README.md)。
- 架构图说明实际边界；README 中的 Mermaid 由文档平台渲染，不代表画布直接支持 Mermaid 文件。
- 新示例先用实际编译器编译，再打开确认画面与关键交互。不要把“编译通过”等同于运行效果正常。
- 不显示虚构的 Stars、下载数或 CI 通过徽章。版本与许可证徽章链接到本仓库事实。
- 本地浏览器画面不能标注为原生侧栏。宿主协议支持与真实 UI 验收分别记录。
- 发布后更新首次 Release 状态、仓库地址与安装入口；当前没有虚构的 clone / Release 链接。
- 更新内容时同步两个 README，并检查相对链接、页内锚点、截图与示例源码的一致性。

详细操作手册保留在 [使用指南](QUICKSTART.md)，安装升级细节保留在 [发布指南](RELEASING.md)，首页只保留首次体验所需步骤。
