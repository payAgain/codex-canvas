# Codex Canvas 1.0.0

本地验收日期：2026-10-10。源码发布日期：2026-10-11。许可证：MIT。状态：历史验收记录，此版本未创建发行标签；首个可下载发行版见 [1.1.1](1.1.1.md)。

## 功能

- 在 Codex 原生侧边面板打开 TSX/JSX 画布，宿主不支持时使用本地浏览器回退。
- 紧凑的 React 报告、图表、表格、架构图和审查画布。
- 文件跟随、独立交互状态、源码版本和失败构建恢复。
- Design mode 点击选区、选择父层、版本化反馈；明确操作才会添加上下文或发送修改请求。
- 可恢复删除，保留外部源文件。

## 正式版修复

- 打开不存在或已删除画布失败后，保留当前有效画布绑定。
- 串行处理同一界面的读取、状态和重新连接，避免快速切换导致服务端绑定顺序错乱。
- 切换画布清除旧选区修改要求和旧源码编辑基线。
- 已删除列表显示自己的数量；首次编译失败时，主题更新不再尝试渲染不存在的构建。
- 固定 MCP 服务名，保留历史服务/资源地址；过期会话只在操作尚未执行时安全重连。
- 可移植包改用用户数据目录，不携带开发机器路径；单独锁定发布依赖。

## 已知边界

- Windows 原生面板已经实际出现；上下文/发送、文件入口和订阅受宿主版本与能力声明限制。协议回归测试不等同于所有宿主功能已实测。
- 普通聊天 TSX 路径链接可能仍打开外部编辑器；请使用 Canvas 工具或插件文件入口。
- 不支持通用 AST 定位、拖拽框选、写入聊天草稿、导出或公网托管。行号提示仅来自唯一文本匹配。
- 数据需要自行备份；生成浏览器代码没有独立 CPU 配额。
- Recharts 2.x 是固定的上游兼容依赖，迁移到 3.x 留待专门兼容性评估。
