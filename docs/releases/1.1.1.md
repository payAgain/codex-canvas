# Codex Canvas v1.1.1

首个可下载的 GitHub 发行版，包含完整的 Codex Canvas 插件、内置 Skill、SDK、已构建工作台与示例。发行日期：2026-10-11；许可证：MIT。

## 下载与安装

- `codex-canvas-1.1.1-portable.zip`：Windows、macOS、Linux 通用安装包，包含原生插件入口、编译器、SDK、示例与锁文件。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

需要 Node.js 22+、支持插件的 Codex 桌面端和提供 `codex plugin` 命令的 Codex CLI。解压 ZIP 到长期保留的目录，在解压根目录运行：

```sh
cd plugins/codex-canvas
npm ci --omit=dev --ignore-scripts --no-audit --no-fund
cd ../..
codex plugin marketplace add . --json
codex plugin add codex-canvas@codex-canvas-local --json
```

安装包不含 `node_modules`，首次安装依赖需要联网。同名 marketplace 已指向旧目录时，先核对并移除旧注册，再添加新目录。重新加载插件；已有聊天仍连接旧服务时重启 Codex。画布数据保存在独立的固定库目录。

在 Codex 中输入：

> 使用 Codex Canvas 插件的原生 MCP App 面板，画出这个项目的架构图。不要打开浏览器或使用 localhost 预览回退。

完整说明见 [使用指南](../QUICKSTART.md) 和 [安装与发布](../RELEASING.md)。

## 功能与改进

- TSX / JSX 单文件画布、文件保存后自动更新、源码版本与独立交互状态；编译失败保留最近成功画面。
- 原生 MCP App 打开设为强制规则；stdio 插件不启动 HTTP 服务、不返回浏览器链接。独立浏览器模式必须显式使用 `--browser` / `--serve`。
- 固定默认画布库，自动迁移旧库并保留原目录；「打开文件」直接浏览库、显示源码路径，支持恢复并打开。
- 跟随宿主、亮白、暖纸、青雾、石墨黑、午夜蓝六种主题选项，选择持久保存。
- 画布列表新增关闭按钮和 Esc；已删除画布可输入完整标题确认永久删除。外部源文件和旧迁移备份保留。
- Design mode 支持点选、选父层、添加选区上下文与明确发送修改要求；宿主不支持聊天接口时可复制选区。
- 六类开发图表示例：函数调用、时序、UML 类、系统架构、模块依赖与状态转换；另附报告、统计和审查示例。
- 修复 CI 的旧版本断言与默认目录断言，增加迁移、永久删除及绑定清理回归。发布先通过三平台类型、构建、22 项测试、锁定依赖安装和归档检查。

## 已知边界

原生 UI 的展示位置与上下文/消息接口取决于 Codex 宿主能力。协议和安装包 CI 不等同于每个平台、每个宿主版本的原生 UI 验收。已有聊天可能需要重新加载插件或重启 Codex 才能连接新版服务。

画布源码只支持从项目 SDK 导入；通用 AST 定位、拖拽框选、写入聊天草稿、导出与公网托管仍在规划中。永久删除不能通过当前库恢复，外部源文件保留。

## English

The first downloadable GitHub release includes the native Codex Canvas plugin, built workbench, SDK, skill and examples. Download `codex-canvas-1.1.1-portable.zip` and `SHA256SUMS.txt`. The same ZIP supports Windows, macOS and Linux. Node.js 22+, Codex desktop plugin support and the Codex CLI are required.

Extract the ZIP into a permanent directory and run the installation commands above. Dependencies are installed from the included lockfile; the ZIP has no bundled `node_modules`. Reload the plugin or restart Codex when an existing chat keeps its old MCP connection.

This version adds mandatory native panel delivery, a persistent library with migration/recovery, six theme options, a drawer close button, confirmed permanent deletion, Design mode and six development diagram examples. Release publication follows cross-platform build, regression, installation and archive checks. Native chat actions still depend on advertised host capabilities; automated checks do not replace native UI acceptance.
