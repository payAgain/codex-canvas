# 1.1.0：默认画布目录与主题

日期：2026-10-11。状态：功能实现、类型与生产构建完成；本机已安装 1.1.0，默认库迁移与浏览器界面已观察。新版原生宿主与跨平台观察仍待完成。

## 用户需求

- 默认路径置于 Codex 插件目录，点击「打开文件」直接浏览默认库，删除后也能找到并恢复。
- 提供不同的主题，让用户能手动切换并保留选择。

## 实现

- 默认库：Codex 用户目录中的 `plugins/codex-canvas/data`，列表入口浏览其中的 `canvases/`。支持 `CODEX_HOME`，显式 `CANVAS_DATA_DIR`、`--data-dir` 或 `dataDirectory` 优先。
- 新目录尚不存在时，迁移旧版平台目录或开发库的持久内容，保留 workspaceId、canvasId、源码、成功构建、交互、偏好、能力记录与删除状态。原目录保留，不复制会话 ready 文件。
- 「打开文件」显示真实目录、当前源码路径、已保存/已删除分类和恢复并打开。浏览库使用已有身份；外部文件导入仍位于单独展开区。
- 「文件信息」显示版本、库中源码路径及外部跟随路径。系统文件夹按钮仅打开服务端选定的默认画布目录，不接受任意命令或 UI 路径。
- 主题：跟随宿主、亮白、暖纸、青雾、石墨黑、午夜蓝。偏好写入 `preferences.json`，工作台、标准组件和自定义 SDK 图形同步配色。
- 切换先等待交互状态保存，再创建候选 iframe；成功渲染后替换旧视图。旧画布以最后成功源码缓存新的主题适配构建，不变更用户源码、发布版本或删除状态。

## 证据与边界

- 类型检查与生产构建通过。遵循项目约束，未新增或运行测试套件。
- 本机安装并启用 1.1.0。旧平台库迁入 Codex 插件目录，原 workspaceId、canvasId、源码/发布版本、构建 hash 和删除状态均保留，旧库仍在原位置。
- 更新后的本地浏览器界面显示默认目录、已保存/已删除分类、保留的源码路径和「恢复并打开」。未恢复用户已经删除的画布。
- 主题面板显示跟随宿主与五种手动主题；选择「暖纸」后工作台已切换，界面显示保存成功，`preferences.json` 保存为 `paper`。本次未观察新版生成画布中的各个 SDK 组件；不能用旧版验收声明新版已经全部通过。
- 原生面板中的更新需要新 MCP 连接；持续中的旧进程可能仍读取旧目录。宿主/系统目录打开能力依平台环境而定。
