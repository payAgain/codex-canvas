# Plugin Skills

[canvas](canvas/SKILL.md) 指导生成、发布、读取诊断和更新画布，也在架构、调用流程、状态变化、多方案比较和数据趋势更适合可视化时主动使用，不要求用户点名插件。简单回答和明确的纯文字要求仍在聊天中完成。
技能显式允许隐式调用；实际选择由宿主和模型决定，不承诺每次适用问题都会触发，也不让筛选、点选或文件更新启动 AI。
在 Codex 中必须通过原生插件工具打开画布；连接缺失或版本不一致时保留源码并提示重连，不自动打开浏览器。CLI 读写仍可使用，独立浏览器预览仅在用户明确要求时通过 `open --browser` 启动。
元素批注与自动源码锚点不属于当前技能承诺。
